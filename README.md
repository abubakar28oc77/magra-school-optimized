## ⚡ দ্রুত শুরু করার নিয়ম (Quick Start)

### ১. ফ্রন্টএন্ড চালানো (Frontend Dev Server):
```powershell
cd frontend
npm run dev
```
ব্রাউজারে খুলুন: `http://localhost:5173`

### ২. ব্যাকএন্ড সার্ভার চালানো (Backend Server):
```powershell
cd backend
npm start
```
সার্ভার চলবে: `http://localhost:5000`

### ৩. প্রোডাকশন বিল্ড তৈরি (Production Build):
```powershell
cd frontend
npm run build
```
এটি `frontend/dist/` ফোল্ডারে মাত্র কয়েক কিলোবাইটের অপ্টিমাইজড ফাইল তৈরি করবে।
